# Oliv

A landing page for a made-up branding agency called Øliv. Built to practice a clean, editorial agency-site layout with hover interactions, not a real business.

## About

I wanted to try putting together a full agency-style page instead of just a hero section — services, a client logo strip, a portfolio grid, a team section, and testimonials, all the way down to a footer. I also added an image transition hover effect on the buttons to make the interactions feel less static.

## Built with

- HTML
- CSS

No frameworks, just plain HTML and CSS.

## Features

- Hero section with headline, subtext, and a CTA button
- Client logo strip
- Four-card services section (Brand Strategy, Visual Identity, Digital Marketing, Management)
- "Selected Work" portfolio grid with category tags on each project, images shown in grayscale by default and switching to full color with a slight zoom-in on hover
- Team section with a "join the team" call-out card
- Testimonial section with client quotes and logos
- Final CTA banner before the footer
- Image transition hover effect on buttons

## Running it locally

```bash
git clone https://github.com/shivamsingh-net/Oliv.git
cd Oliv
```

Just open `index.html` in your browser after that. Nothing else needed.

## What I was practicing

- Structuring a full multi-section agency landing page, not just a hero
- Building a portfolio/work grid with consistent card styling
- Adding a hover transition effect on buttons using just CSS
- Using CSS filters (grayscale) combined with a transform/scale on hover to make images pop with color and zoom in
- Laying out a team section and testimonial section that feel cohesive with the rest of the page
